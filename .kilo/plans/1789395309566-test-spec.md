# Test Specification

## Overview
This document describes the test suite for validating the search index functionality. Tests verify correct results for known search queries against the indexed data.

## Test File
- Path: `tests/test-search.js`
- Runner: `node tests/test-search.js`

## Test Cases

### Test 1: Literal Search for "ZigZagLayoutConfig"
**Objective**: Verify 6 matches found for "ZigZagLayoutConfig"

**Expected Results**:
- Total match count: 6
- Should find occurrences across:
  - `ZigZagLayoutConfig.java` (interface definition and imports)
  - `ZigZagLayoutPlugin.java` (usage in code)

**Assertion**:
```javascript
const results = await searchIndex("ZigZagLayoutConfig");
const totalMatches = countMatches(results);
assert.strictEqual(totalMatches, 6, "Expected 6 matches for ZigZagLayoutConfig");
```

## Test Structure

```javascript
// tests/test-search.js
import { test } from 'node:test';
import { strictEqual } from 'node:assert';
import { searchIndex } from '../script/search.js';

async function countMatches(results) {
  // Helper to count total line matches from result structure
  let count = 0;
  for (const pluginResults of Object.values(results)) {
    for (const result of pluginResults) {
      for (const lines of Object.values(result.files)) {
        count += lines.length;
      }
    }
  }
  return count;
}

test('search ZigZagLayoutConfig returns 6 matches', async () => {
  const results = await searchIndex("ZigZagLayoutConfig");
  const matches = await countMatches(results);
  strictEqual(matches, 6);
});

test('search item != null returns 2 matches', async () => {
  const results = await searchIndex("item != null");
  const matches = await countMatches(results);
  strictEqual(matches, 2);
});

test('search RunePouchPlacement returns 6 matches', async () => {
  const results = await searchIndex("RunePouchPlacement");
  const matches = await countMatches(results);
  strictEqual(matches, 6);
});
```
